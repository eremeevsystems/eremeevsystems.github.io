Демонстрационный проект: RequestFlow Mini

Система управления заявками, созданная для демонстрации нашего подхода к разработке клиент-серверных приложений. Реализует типовой процесс обработки внутренних заявок: создание → назначение исполнителя → выполнение → смена статуса → история изменений.

Реализовано: авторизация и JWT-аутентификация, ролевая модель доступа, управление заявками и статусами, история изменений, REST API, C# WinForms-клиент, PostgreSQL, миграции БД, Docker.
